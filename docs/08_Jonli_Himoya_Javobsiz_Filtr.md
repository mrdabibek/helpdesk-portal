# Jonli himoya — Javobsiz murojaatlar
Joylashuv: agent chap navigatsiyasi va navbatning doim ko‘rinadigan “Javobsiz” filtri. Yonida dinamik count.

Qoida: holat Yangi / Jarayonda / Qayta ochilgan va oxirgi ommaviy xabar mijozniki.
Ichki izoh va holat voqealari hisobdan chiqariladi.
Yechildi / Yopilgan kirmaydi.
Agent ommaviy javob berganda count kamayadi. Mijoz yana yozganda yoki muammoni qayta ochganda ko‘payadi.
Bo‘sh natija: “Murojaatlar topilmadi” va filtrlarni tozalash amali.

## 60 soniyalik ko‘rsatish
1. Agent paneli → Javobsiz murojaatlar.
2. #HD-8492 ni ochish, ichki izoh saqlash.
3. Filtrda murojaat qolganini ko‘rsatish.
4. Ommaviy javob yozish; qabul qiluvchi va matnni tekshirish; yuborish.
5. Filtrdan murojaat chiqqanini ko‘rsatish.
6. Mijoz portalida javob ko‘rinadi, ichki izoh ko‘rinmaydi.
Aytiladigan fikr: “Filtr statusdan ko‘ra so‘nggi ommaviy xabarga qaraydi. Ichki izoh mijozga javob hisoblanmaydi.”
